# MVC To-Do List

Консольний застосунок для керування списком завдань, створений на Python із використанням архітектурного шаблону MVC (Model–View–Controller).

## Можливості
- Додавання завдань
- Перегляд списку завдань
- Видалення завдань
- Збереження завдань у файл `tasks_db.txt`

## Структура проєкту
- `model.py` — модель даних та бізнес-логіка
- `view.py` — консольний інтерфейс
- `controller.py` — обробка команд та взаємодія компонентів
- `main.py` — запуск програми
- `tasks_db.txt` — файл збереження завдань

## Запуск
Потрібен Python 3.

```bash
python main.py
```

## Доступні команди
- `додати`
- `показати`
- `видалити`
- `вийти`

Практичне завдання № 1 з дисципліни «Архітектура програмного забезпечення».
